# NTC CC105 Student Roster Manager

A C++ fixed-capacity student roster management system for NTC CC105 Data Structures with Laboratory.

## Features

- Add student records
- Search students by ID using linear search
- Remove students by ID
- Safely inspect records by array index
- Display the complete student roster
- Prevent duplicate student IDs
- Prevent exceeding the 50-student capacity
- Includes performance reflection on array operations

## Capacity

Maximum roster capacity: 50 students.

## Testing

The program was tested for:

- Adding student records
- Duplicate ID rejection
- Removing a student and shifting records
- Safe access with valid and invalid indexes
- Empty roster handling
- Full roster capacity
